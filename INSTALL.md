# ShyFox (personal fork) — install

Customized [ShyFox](https://github.com/Naezr/ShyFox) by Naezr, with fixes for
**Firefox 156 (Nova)**. This repo is a fork; `upstream` points at Naezr.

## Prerequisites

- Firefox (tested on 156).
- Extensions:
  - [Userchrome Toggle Extended](https://addons.mozilla.org/firefox/addon/userchrome-toggle-extended/)
    — drives the `titlepreface` marks that hide/show the navbar, toolbar and sidebar.
  - [Sidebery](https://addons.mozilla.org/firefox/addon/sidebery) — the sidebar.
- In `about:config`, allow unsigned extensions (needed for the toggler):
  `xpinstall.signatures.required = false`.

## Install

1. Copy the **`chrome/`** folder and **`user.js`** into your Firefox profile
   directory (find it at `about:support` → "Profile Folder", e.g.
   `~/.mozilla/firefox/<random>.default-release/`).
2. Restart Firefox.
3. Set up Sidebery and the toggle extension (see the upstream README for the
   full walkthrough).

`user.js` sets the required prefs:
`toolkit.legacyUserProfileCustomizations.stylesheets`,
`sidebar.revamp = false`, `svg.context-properties.content.enabled`,
`layout.css.has-selector.enabled`.

## Firefox 156 (Nova) fixes in this fork

- `shy-global.css`, `shy-sidebar.css`, `shy-toolbar.css`, `shy-navbar.css`:
  FF156 removed the `chromehidden` attribute, so the old
  `:not([chromehidden=""])` selectors always matched and collapsed the whole
  toolbar (`#navigator-toolbox { display:none }`), breaking hover-reveal. The
  checks are inverted to `:not([chromehidden])` / `[chromehidden]`.
- `shy-navbar.css`: FF156 rendered the URL bar as a flex `moz-urlbar`, so the
  `#urlbar-container::before` placeholder became a second flex item (two URL
  bars). It is now `position:absolute; inset:0; z-index:-1` behind the bar.
- `userChrome.css`: a small Nova compat block (`body { contain:none }`,
  `.chrome-block { overflow:visible }`, ...) and the `wallust-imports.css`
  import.

## Notes

- `chrome/ShyFox/wallust-imports.css` holds colors generated by wallust/pywal.
  Replace it with your own scheme or delete it and remove its `@import` from
  `chrome/userChrome.css`.
